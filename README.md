# EduPulse | Web-based study tool

EduPulse is a web-based learning companion designed for Information Systems students. It offers interactive quizzes, customizable flashcards, and a chatbot that delivers study tips, jokes, and general knowledge. Built with HTML, CSS, and JavaScript, EduPulse emphasizes clarity, gamification, and responsive design.

# Features

- 🧠 Quiz Arena with XP rewards
- ⚡️ Flashcard Hub for concept mastery
- 🤖 EduBot AI for tips, jokes, and facts
- 🌙 Light/Dark theme toggle
- 📊 XP tracking and level milestones
- 💾 LocalStorage-based progress saving

# Built With

- HTML5
- CSS3 (Glassmorphism + Responsive Design)
- JavaScript (Modular logic, LocalStorage)

  # Usage Guide
EduPulse is organized into five interactive pages, each designed to support different aspects of student learning:
🏠 Home (index.html)
- Landing page with navigation to all modules.
- Clean layout and theme toggle for personalized experience.
📊 Dashboard (dashboard.html)
- Displays XP progress and level milestones.
- Tracks your learning achievements across quizzes.
🎯 Quiz (quiz.html)
- Select a module and difficulty level.
- Answer timed questions and earn XP for correct answers.
- Mission-based layout with progress tracking.
⚡️ Flashcards (flashcards.html)
- Create, flip, and delete custom study cards.
- Save difficult concepts for quick review.
- Uses LocalStorage to persist your flashcard library.
📝 Notepad (notepad.html)
- Take quick notes while studying or reviewing.
- Simple text input with persistent storage.
- Ideal for jotting down reminders, formulas, or summaries.
ℹ️ About (about.html)
- Provides background information on EduPulse: its purpose, vision, and features.
- Introduces the team or project context (e.g., student project, educational tool).
- Explains how EduPulse supports learning through quizzes, flashcards, and note-taking.
- Serves as a reference page for new users to understand the platform’s mission.
